# Global Exchange
Plataforma de alta performance e baixa latência para negociação de ativos digitais.
Desenvolvida com uma arquitetura robusta de microserviços orientada a eventos para garantir máxima escalabilidade e segurança.

### Componentes do Sistema:
- **matching-engine**: Motor de casamento de ordens (Order Book) proprietário de alta velocidade.
- **api-gateway**: Ponto de entrada único e unificado para APIs REST e WebSockets.
- **wallet-service**: Microsserviço isolado para gerenciamento seguro de carteiras, saldos, depósitos e saques.
- **frontend-web**: Interface de usuário responsiva e otimizada para negociações em tempo real.
